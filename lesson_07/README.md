# Занятие 7 · Докстринги в VS Code: генератор и проверка

Практическая работа по главе 4.10. Вы ставите генератор докстрингов
autoDocstring и проверку Ruff, записываете вид заготовки в настройки проекта,
создаёте сниппет, документируете два модуля и доводите их до чистой проверки.
На каждом шаге делаете снимок и заполняете готовый отчёт.

Глава 4.10:
https://algorthimization-course-vvodnoe.vercel.app/mdk0101-razrabotka-modulei/lessons/04-docstrings-i-dokumentaciya/10-vs-code.html

## Как делать снимки

- Снимок окна VS Code целиком, а не всего экрана: на macOS
  **Cmd + Shift + 4**, затем пробел и щелчок по окну; на Windows
  **Win + Shift + S**, режим «Окно».
- Текст на снимке должен читаться без увеличения. Если окно большое,
  уменьшите его до половины экрана перед снимком.
- Формат PNG, имя — строго из таблицы. Тогда снимок встанет в отчёт сам.
