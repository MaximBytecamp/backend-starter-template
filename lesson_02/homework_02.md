# Домашнее задание № 2 · своё окружение и первый модуль

**Занятие 2 — окружение, модули и пакеты, тема 2 «Структура проекта»**

Максим Николаевич не хочет задавать вам домашнее задание. Но очень хочет.

Работа на один вечер. Вы берёте готовую программу из одного файла, запускаете
её в собственном окружении, подключаете одну библиотеку и выносите расчёты
в отдельный модуль. Программа при этом должна печатать те же числа.

## 1. Запустить заготовку

Создайте папку `lesson_02/trip/` и скопируйте в неё `start/trip.py`.
Откройте папку `trip` в VS Code и запустите:

| macOS / Linux | Windows |
|---|---|
| `python3 trip.py` | `py trip.py` |

Должно напечататься:

```text
ОТЧЁТ ПО ПОЕЗДКЕ
--------------------------------
записей: 10
всего потрачено: 7900 ₽
средняя трата: 790.00 ₽
```

## 2. Создать окружение

В той же папке создайте окружение и активируйте его (глава 2.1):

| Шаг | macOS / Linux | Windows (PowerShell) |
|---|---|---|
| создать | `python3 -m venv .venv` | `py -m venv .venv` |
| активировать | `source .venv/bin/activate` | `.venv\Scripts\activate` |

В начале строки терминала появится `(.venv)`. Выберите этот интерпретатор
в VS Code: внизу справа должно стоять `.venv` (глава 2.2).

## 3. Подключить библиотеку

Поставьте Rich (глава 2.3):

```text
pip install rich
```

В начало `trip.py`, сразу под комментарием, добавьте импорт, а в функции
`format_report` выделите заголовок отчёта:

```python
from rich import print
```

```python
        "[bold green]ОТЧЁТ ПО ПОЕЗДКЕ[/bold green]",
```

Запустите программу: заголовок станет зелёным и жирным, числа те же.
Запишите зависимости в файл:

```text
pip freeze > requirements.txt
```

## 4. Вынести расчёты в модуль

Создайте рядом с `trip.py` файл `calculator.py` и перенесите в него две
функции — `calculate_total` и `calculate_average` (глава 2.4). В `trip.py`
вместо них в начале файла, рядом с импортом Rich, появится строка:

```python
from calculator import calculate_total, calculate_average
```

Запустите `python trip.py`: отчёт должен быть таким же, как в пункте 1.

## 5. Написать README

В `lesson_02/trip/README.md` — несколько строк:

- что делает программа, одним предложением;
- команды: создать окружение, активировать, поставить зависимости
  (`pip install -r requirements.txt`), запустить;
- что программа печатает.

## Что сдать

Папка `lesson_02/trip/`:

```
trip.py           запуск и печать отчёта
calculator.py     два расчёта
requirements.txt  записанные зависимости
README.md         как запустить
```

Папку `.venv` в репозиторий не добавляйте: её у себя создаёт каждый.

Сдача: коммит `hw-02: …` в `main` и отправка на GitHub.

## Критерии, 10 баллов

| Что проверяется | Баллы |
|---|---|
| Окружение создано, Rich стоит, `requirements.txt` есть | 3 |
| Расчёты в `calculator.py`, `trip.py` импортирует их оттуда | 3 |
| Программа запускается и печатает те же числа | 2 |
| README с командами запуска, `.venv` не в репозитории | 2 |

## Если сдаёте на Go

То же самое на Go (главы 2.1–2.4, ветка Go): `go mod init trip`, библиотека
`github.com/fatih/color` через `go get`, расчёты в отдельном файле
`calculator.go` того же пакета, запуск `go run .`. В README — команды
`go mod download` и `go run .`. Числа те же.
