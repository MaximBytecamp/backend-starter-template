# Занятие 4 · практикум «Младший разработчик: первая неделя»

Работа в браузере по двум темам: окружение проекта (тема 2) и аннотации типов
(главы 4.1 и 4.2). Установка не нужна.

Практикум:
https://algorthimization-course-vvodnoe.vercel.app/mdk0101-razrabotka-modulei/lessons/05-praktikum-podpisi/index.html

## Суть работы

Вы неделю работаете стажёром в студии разработки. Задания приходят четырьмя
письмами от тимлида:

1. **Рабочее место** — расставить команды от архива до запуска проекта,
   решить, какие файлы уходят в репозиторий, найти причину проблем с `.venv`
   из чата стажёров.
2. **Подписи по заявкам** — по описанию заказчика собрать подпись функции:
   нужные параметры и тип каждого параметра и результата, в том числе `str | None`.
3. **Вызовы и подпись** — решить, какие вызовы подходят к подписи функции.
4. **Подпись вручную** — написать строку `def` целиком.

После кнопки «Сдать работу» ответы закрываются и открывается рецензия
с баллами и разбором каждого задания.

## Что сдать

В папку `lesson_04/` положить файл рецензии `podpisi_Фамилия_Имя.md`.
Его скачивают на вкладке «Рецензия» после сдачи работы: сначала вписать
фамилию, имя и группу, затем нажать «Скачать отчёт .md». Имя файла не менять.

Без файла рецензии работа не принимается.
