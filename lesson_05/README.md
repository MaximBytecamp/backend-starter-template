# Занятие 5 · Проверка типов до запуска

Домашнее задание по главам 4.3–4.5 книги темы 4. Вы настраиваете проверку типов
в своём редакторе, проверяете файл с ошибками в редакторе и в терминале, затем
доводите проект «Отчёт кафе» до чистой проверки и оформляете отчёт в `.md`
со своими снимками экрана.

Вариант выбираете сами — по языку, на котором работаете в курсе:

| Вариант | Чем проверяете | Проект | Шаблон отчёта |
|---|---|---|---|
| **Python** | Pylance в VS Code и mypy в терминале | `otchet-kafe-bez-tipov` — 17 функций без аннотаций | [`otchet_python.md`](otchet_python.md) |
| **Go** | gopls в VS Code, `go build` и `go vet` в терминале | `otchet-kafe-go-oshibki` — 12 ошибок типов | [`otchet_go.md`](otchet_go.md) |

## Что сделать

Работа идёт в четыре части. Каждая часть — раздел отчёта: в шаблоне уже
расставлены заголовки, таблицы и места под снимки, вы заполняете их своим.

**1. Подготовка редактора.**
Python: расширения Python и Pylance, интерпретатор из `.venv`, режим проверки
`basic` в настройках проекта (глава 4.3, §3, шаги 1–4).
Go: расширение Go и gopls, версия Go в строке состояния (глава 4.3, §3, шаги 1–2).

**2. Проверка файла с ошибками в редакторе.**
Создайте файл для опытов из главы 4.3, §2: `proba.py` для Python или
`proba/main.go` для Go — два вызова с аргументами не того типа. Снимите
подчёркивания, всплывающее сообщение и панель Problems, разберите сообщение
по частям своими словами.

**3. Проверка в терминале.**
Python: `mypy proba.py` до и после исправления, разбор одной строки вывода,
таблица из главы 4.3, §4 — сколько сообщений даёт каждый режим Pylance.
Go: `go build ./...` до и после исправления, разбор одной строки ошибки,
файл из главы 4.3, §4 под `go vet` и staticcheck.

**4. Проект до чистой проверки.**
Python: расставить аннотации во всех 17 функциях `otchet-kafe-bez-tipov` по
порядку из главы 4.5, записать, сколько ошибок mypy остаётся после каждого
пакета, и получить `Success`.
Go: исправить 12 ошибок в `otchet-kafe-go-oshibki` по порядку из главы 4.5,
записать, сколько ошибок показывают терминал и панель Problems после каждого
пакета, и получить чистые `go build ./...` и `go vet ./...`.

В обоих вариантах тесты должны проходить, а отчёт программы — совпадать
с исходным: итог `4 937,50 ₽`.

## Как оформить отчёт

1. Скопируйте шаблон своего варианта и назовите копию
   `otchet_Фамилия_Имя.md`, например `otchet_Ivanova_Anna.md`.
2. Снимки экрана кладите в папку `lesson_05/img/` под теми именами, которые
   указаны в шаблоне: у варианта Python они начинаются с `py-`, у варианта Go —
   с `go-`. В папке уже лежат картинки-заглушки с этими именами — замените
   их своими снимками, и они встанут в отчёт сами. Заглушки другого варианта
   удалите.
3. Места для вашего текста отмечены строками `✏️`. Вместо них напишите свой
   текст, саму пометку удалите. Вывод терминала вставляйте текстом в блоки
   кода, а не снимком: так его можно прочитать и проверить.
4. Перед сдачей откройте отчёт в предпросмотре VS Code (**Ctrl+Shift+V**,
   на macOS **Cmd+Shift+V**) и проверьте, что все снимки видны и ни одной
   пометки `✏️` не осталось.

Снимок делается так: Windows — **Win+Shift+S**, macOS — **Cmd+Shift+4**,
Linux — клавиша **PrtSc** или программа «Снимок экрана». Снимайте окно
редактора, а не весь экран; на снимке должно быть видно то, о чём написано
в подписи.

## Что сдать

В папке `lesson_05/`:

| Файл или папка | Что в нём |
|---|---|
| `otchet_Фамилия_Имя.md` | заполненный отчёт своего варианта |
| `img/` | ваши снимки под именами из шаблона, заглушек не осталось |
| `otchet-kafe-bez-tipov/` или `otchet-kafe-go-oshibki/` | проект после части 4: проверка чистая, тесты проходят |

Файл для опытов (`proba.py` или папку `proba/`) в сдачу не включайте.
Папку `.venv` в репозиторий не добавляйте.

## Критерии

| За что | Баллы |
|---|---|
| Редактор настроен: снимки 1–2 части, проверка работает | 2 |
| Сообщение проверки разобрано по частям своими словами | 2 |
| Вывод терминала до и после исправления, разбор строки, таблица режимов или уровней | 2 |
| Проект доведён до чистой проверки, тесты проходят, отчёт программы прежний | 3 |
| Отчёт оформлен: все снимки на месте, пометок `✏️` не осталось, выводы своими словами | 1 |

Максимум 10 баллов. Работа без снимков или со снимками-заглушками, а также
работа, в которой вывод терминала не совпадает со снимками, возвращается на
доработку.

Сдача: ветка `hw-05`, Pull Request в свою `main`. В описании Pull Request
укажите вариант (Python или Go) и последнюю строку проверки проекта.
