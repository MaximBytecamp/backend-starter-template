# Занятие 5 · Проверка типов до запуска

Домашнее задание по главам 4.3–4.5 книги темы 4. Вариант выбираете по языку,
на котором работаете в курсе:

| Вариант | Чем проверяете | Проект | Шаблон отчёта |
|---|---|---|---|
| **Python** | Pylance и mypy | `otchet-kafe-bez-tipov` | [`otchet_python.md`](otchet_python.md) |
| **Go** | gopls, `go build`, `go vet` | `otchet-kafe-go-oshibki` | [`otchet_go.md`](otchet_go.md) |

Книга: https://algorthimization-course-vvodnoe.vercel.app/mdk0101-razrabotka-modulei/lessons/04-docstrings-i-dokumentaciya/03-proverka-tipov.html
— главы 4.3, 4.4 и 4.5, язык переключается кнопкой **Python / Go** вверху страницы.

Проекты лежат в [`materials/tema-04-annotacii-tipov`](../materials/tema-04-annotacii-tipov/):
скопируйте свой в `lesson_05/`.

## Что сделать

1. Настроить проверку в VS Code (глава 4.3, §3).
2. Создать файл с двумя неверными вызовами (глава 4.3, §2) и проверить его
   в редакторе и в терминале.
3. Довести проект до чистой проверки по порядку из главы 4.5: в Python —
   расставить аннотации во всех функциях, в Go — исправить все ошибки типов.
   Тесты должны проходить, итог отчёта программы — `4 937,50 ₽`.
4. Заполнить отчёт.

## Отчёт

Скопируйте шаблон своего варианта и назовите `otchet_Фамилия_Имя.md`.
Места для вашего текста отмечены `✏️`. Снимки кладите в `lesson_05/img/`
под именами из шаблона — вместо картинок-заглушек; заглушки другого варианта
удалите. Вывод терминала вставляйте текстом в блоки кода.

## Что сдать

В `lesson_05/`: отчёт `otchet_Фамилия_Имя.md`, папку `img/` со своими снимками
и исправленный проект. Файл для опытов и `.venv` не добавляйте.

Сдача: коммит `hw-05: …` в `main` и отправка на GitHub.

## Критерии

| За что | Баллы |
|---|---|
| Редактор настроен, ошибки видны в редакторе и в терминале | 3 |
| Сообщение проверки разобрано своими словами | 2 |
| Проект доведён до чистой проверки, тесты проходят | 4 |
| Все снимки свои, выводы написаны | 1 |

Работа со снимками-заглушками возвращается на доработку.
