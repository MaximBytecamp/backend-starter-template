## Проверить, что заготовка работает

```bash
cd lesson_05
python3 library.py
```

Должен напечататься список должников и строка `всего штрафов: 510`.
Если сумма другая — посмотрите, из какой папки вы запустились: путь
к данным в файле относительный, и это первое, что вы почините.
