## Содержание практикума

Практикум закрепляет темы 2 и 4: окружение проекта и подписи функций
с аннотациями. Работа идёт на рабочем столе в браузере: младший разработчик
студии «Верстак» получает от тимлида четыре письма.

| Письмо | Что отрабатывает | Баллы |
|---|---|---|
| 1 · рабочее место | порядок команд для окружения, какие файлы попадают в Git, ответы на вопросы из чата команды | 2 |
| 2 · подписи по заявкам | подпись функции по описанию задачи: имена параметров, типы, результат | 4 |
| 3 · вызовы и подпись | подходит ли вызов к подписи: пять подписей, по восемь вызовов | 2 |
| 4 · подпись вручную | четыре подписи, написанные без подсказок | 2 |

После четырёх писем открывается рецензия за неделю: баллы, ответы и темы
для повторения.

### Что нужно помнить из тем 2 и 4

- Окружение: `python -m venv .venv`, активация, `pip install -r requirements.txt`;
  `.venv` в Git не попадает.
- Подпись функции: `def имя(параметр: тип, параметр: тип = значение) -> тип:`.
- Несколько возможных типов в одном месте — `int | str`, отсутствие значения —
  `None`, коллекции — `list[int]`, `dict[str, int]`.
