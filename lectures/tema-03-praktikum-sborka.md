## Содержание практикума

Практикум закрепляет тему 2 на двух новых проектах. Правила те же: у модуля
одна обязанность, расчёты возвращают значения и ничего не печатают, проект
запускается через `python -m app.main` и проходит тесты.

### Работа 1 · Иерархия проекта

Проект cafe-report прислали архивом: файлы с пробелами и кириллицей в именах,
старые версии, кэш `.pyc`, файл `.env` с токеном, служебный `.DS_Store`.
Нужно собрать из них проект с пакетами `app/services` и `app/utils`,
данными в `data/`, тестами в `tests/`, документацией в `docs/`. Импорты
в коде показывают, какой файл куда относится. Лишнее не попадает
в репозиторий: для этого `.gitignore`.

Оценка: раскладка — 3 балла, запуск с ожидаемым результатом — 3, тесты — 2,
README с деревом проекта — 2.

### Работа 2 · Разделение на модули

Проект text-kit — один файл `main.py` со всеми функциями и готовые тесты.
Функции нужно разнести по четырём модулям: `services/statistics.py`,
`services/validation.py`, `utils/dates.py`, `utils/text.py`. Вывод программы
после разделения должен совпасть с прежним, тесты — пройти.

Оценка: раскладка функций — 3 балла, запуск с прежним выводом — 3,
тесты — 2, README с принципом разделения — 2.
