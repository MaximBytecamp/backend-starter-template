# backend-starter · МДК.01.01 «Разработка программных модулей»

Ваш репозиторий на всю дисциплину. Отсюда вырастет сервис: код, тесты,
миграции, стенд. Сейчас в нём только домашнее задание первого занятия —
остальное появится на парах.

## Сделать репозиторий своим

Нажмите **Use this template → Create a new repository**, назовите
`backend-<фамилия>` и выберите видимость. Появится собственный репозиторий
с чистой историей, он останется у вас и после дисциплины. Форк не подходит:
он остаётся привязан к исходному.

## Что понадобится

Python 3.12 и git. На Windows при установке Python отметьте галочку
*Add Python to PATH*. Проверить, что стоят:

| | macOS / Linux | Windows |
|---|---|---|
| Python | `python3 --version` | `py --version` |
| git | `git --version` | `git --version` |

Что не встало — записываете в третий пункт домашнего задания, разберём
на следующей паре.

## Что где лежит

```
lesson_01/      занятие 1: домашнее задание и место для вашего кода
```

На каждое занятие — своя папка. Код и заготовки я выдаю на паре, вы кладёте
их туда же. Папку следующего занятия делаете копией предыдущей:
`cp -r lesson_01 lesson_02` (на Windows — `Copy-Item -Recurse lesson_01 lesson_02`).

## Как сдавать

```bash
git switch -c hw-01                       # ветка на задание
git add lesson_01
git commit -m "hw-01: разбор знакомого сервиса"
git push -u origin hw-01
```

Дальше на GitHub открываете **Pull Request** в свою `main` и коротко пишете,
что сделали. Срок — до начала следующего занятия.

Всё то же самое можно делать мышкой в VS Code, без терминала. Разбор
со скриншотами: [коротко](docs/git/README.md) — основные операции
с размеченными кадрами, [подробно](docs/git/FULL.md) — каждый шаг,
включая типичные ошибки.

## Правила

- Сервис должен подниматься из чистого клона на чужом компьютере — это
  проверяется на защите.
- ИИ можно после собственной попытки: разобрать ошибку, предложить тесты,
  причесать документацию. Вставленный код нужно понимать — на review спрошу,
  почему сделано именно так.
- На диагностике, контрольных и экзамене — без ИИ и поиска.
