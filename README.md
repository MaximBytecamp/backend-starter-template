# backend-starter · МДК.01.01 «Разработка программных модулей»

Ваш репозиторий на всю дисциплину. Отсюда вырастет сервис: код, тесты,
миграции, стенд. Папки занятий появляются по ходу курса, забирать их
из шаблона вы будете сами, это описано в задании каждого занятия.

## Сделать репозиторий своим

Нажмите **Use this template → Create a new repository**, назовите
`backend-<фамилия>` и выберите видимость. Появится собственный репозиторий
с чистой историей, он останется у вас и после дисциплины. Форк не подходит:
он остаётся привязан к исходному.

## Что понадобится

Python 3.12 и git. На Windows при установке Python отметьте галочку
*Add Python to PATH*. Проверить, что стоят:

| | macOS / Linux | Windows |
|---|---|---|
| Python | `python3 --version` | `py --version` |
| git | `git --version` | `git --version` |

Если что-то не встало, запишите это в третий пункт домашнего задания,
разберём на следующей паре.

## Что где лежит

```
lesson_01/      занятие 1: домашнее задание и место для вашего кода
lesson_02/      занятие 2: окружение, модули и пакеты, заготовка и задание
docs/git/       разбор работы с git и GitHub со скриншотами
```

На каждое занятие своя папка. Код и заготовки я выдаю на паре, вы кладёте
их туда же.

| Папка | Занятие | Что сдаёте | Ветка |
|---|---|---|---|
| `lesson_01` | 1 · знакомый сервис изнутри | `homework_01.md` | `hw-01` |
| `lesson_02` | 2 · окружение, модули и пакеты | папку `trip-report`: пакет, тесты, README | `hw-02` |
| `lesson_03` | 3 · практикум «Сборка проекта» | папки `cafe-report` и `text-kit` | `hw-03` |

Новые папки занятий появляются в шаблоне по ходу курса. Забрать папку проще
всего кнопками: в шаблоне на GitHub **Code → Download ZIP**, распаковать
и положить нужную папку к себе в проект.

## Как сдавать

Одно задание — одна ветка — один Pull Request. Ветка называется по номеру
задания: `hw-01`, `hw-02`. Создаёте ветку, кладёте работу в папку занятия,
коммитите, публикуете ветку и открываете Pull Request в свою `main`,
коротко описав, что сделали. Сдать нужно до начала следующего занятия.

Всё это делается кнопками в VS Code, терминал не нужен:

| Что нужно | Где посмотреть |
|---|---|
| создать ветку и переключиться | [ветки](docs/git/README.md#5-ветки) |
| отобрать файлы и закоммитить | [изменения и коммиты](docs/git/README.md#3-изменения-и-коммиты) |
| опубликовать ветку и открыть Pull Request | [ветки на GitHub и Pull Request](docs/git/README.md#6-ветки-на-github-и-pull-request) |
| забрать чужие правки, разобрать конфликт | [pull и fetch](docs/git/README.md#8-совместная-работа-pull-и-fetch) |

Полная версия разбора со всеми экранами — [docs/git/FULL.md](docs/git/FULL.md).

## Правила

- Сервис должен подниматься на чужом компьютере из скачанного репозитория,
  это проверяется на защите.
- ИИ можно после собственной попытки: разобрать ошибку, предложить тесты,
  причесать документацию. Вставленный код нужно понимать — на review спрошу,
  почему сделано именно так.
- На диагностике, контрольных и экзамене ИИ и поиск закрыты.
